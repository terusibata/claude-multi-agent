# PPTX Reader Skill (AI最適化版)

PowerPoint (.pptx) ファイルを解析し、AI（LLM）が効率的に理解できる構造化出力を返すスキル。

## 依存関係

- Python 3 + `python-pptx`（初回実行時に自動インストール）

## コマンド

スクリプトパス: `<このスキルのディレクトリ>/scripts/read_pptx.py`

```bash
# デフォルト: AI向けコンパクト出力
python3 scripts/read_pptx.py <pptx_file>

# スライド範囲指定
python3 scripts/read_pptx.py <pptx_file> --slides 1-3
python3 scripts/read_pptx.py <pptx_file> --slides 2,5,8

# キーワード検索
python3 scripts/read_pptx.py <pptx_file> --search "キーワード"

# 目次のみ（大量スライド時の概要把握に有効）
python3 scripts/read_pptx.py <pptx_file> --summary

# 出力形式の切替
python3 scripts/read_pptx.py <pptx_file> --format ai      # デフォルト
python3 scripts/read_pptx.py <pptx_file> --format human    # 人間向け
python3 scripts/read_pptx.py <pptx_file> --format json     # JSON (空値省略)
```

## AI向け出力フォーマットの設計思想

デフォルトの `--format ai` は以下の原則で設計されている:

1. **2層構造**: ヘッダー（メタ+目次）→ 各スライド詳細。まず全体像を掴み、必要なスライドだけ読める
2. **空値完全省略**: 情報がないフィールドは一切出力しない
3. **セマンティックタグ**: プレースホルダーの役割（タイトル/本文/サブタイトル/ノート等）を識別して表示
4. **装飾なし**: 絵文字、罫線、冗長なラベルを排除し情報密度を最大化
5. **書式は差分のみ**: 太字など意味のある書式だけ括弧内に付記
6. **日本語レイアウト名**: 日本語版PowerPointのレイアウト名を正規化して表示

### 出力例

```
[PPTX] 2024年度事業計画 | 15枚 | 作成:山田太郎 | 更新:2024-04-01 10:30:00
[目次] S1:表紙 / S2:目次 / S3:現状分析 / S4:課題整理 / S5:提案概要

== S1 (表紙) 「2024年度事業計画」
  [タイトル] 2024年度事業計画
  [サブタイトル] 経営企画部
  [ノート] 冒頭5分、全体の流れを説明

== S3 (タイトル+本文) 「現状分析」
  [タイトル] 現状分析
  [本文]
    売上高は前年比105% (強調: 105%)
    営業利益率は12.3%に改善
  [表] 4行x3列
    H| 項目 | 前年 | 今年
    1| 売上高 | 100億 | 105億
    2| 営業利益 | 10億 | 12.9億
    3| 利益率 | 10.0% | 12.3%
```

## ワークフロー

1. PPTXファイルが添付されたら `/mnt/user-data/uploads/` のパスを確認
2. 大量スライド（10枚以上）の場合はまず `--summary` で目次を確認
3. 必要に応じて `--slides` で範囲を絞って詳細を取得
4. 特定の内容を探す場合は `--search` を使用
5. ユーザーに結果をまとめて返答する

## 注意事項

- 画像の中身（OCR）は非対応。画像の存在とメタ情報のみ返す
- グラフ・SmartArtの詳細解析は非対応（テキスト部分のみ抽出）
- テーブルのヘッダー行は自動判定（1行目が短いラベル的テキストの場合）
